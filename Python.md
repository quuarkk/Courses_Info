## **Суть: print() и input()**

**print()** — вывод на экран
```python
print("Текст")           # Просто текст
print(1, 2, 3)          # Несколько значений (через пробел)
print()                 # Пустая строка
```

**input()** — ввод от пользователя
```python
name = input("Имя: ")   # Сохраняет введённое в переменную
```

**Важно:**
- `input()` всегда возвращает **строку**
- Кавычки: `"текст"` или `'текст'` — одинаково
- Переменные хранят данные

**Пример:**
```python
name = input("Как вас зовут? ")
print("Привет,", name)
```

## **Параметры sep и end**

**sep** — разделитель между аргументами print()
```python
print('a', 'b', 'c')          # a b c
print('a', 'b', 'c', sep='-') # a-b-c
print('a', 'b', 'c', sep='')  # abc
```

**end** — что добавлять в конце вывода (по умолчанию \n — новая строка)
```python
print('Привет', end=' ')      # Не переходит на новую строку
print('мир!')                  # Привет мир!
print('Строка1', end='...')   # Строка1...
print('Строка2')               # Строка1...Строка2
```

**Использование вместе:**
```python
print('1', '2', '3', sep='.', end='!')  # 1.2.3!
```

## **Множественное присваивание**

**Запись в одну строку:**
```python
a, b, c = 1, 2, 3  # a=1, b=2, c=3
x = y = z = 0      # x=0, y=0, z=0
```

**Обмен значений:**
```python
a, b = 1, 2
a, b = b, a  # Теперь a=2, b=1
```

## **PEP 8 и комментарии**

**Комментарии:**
```python
# Однострочный комментарий
print('Hello')  # Комментарий после кода

"""
Многострочный
комментарий
(на самом деле строка)
"""
```

**Основные правила PEP 8:**
- Отступы: **4 пробела** (не табуляция)
- Пробелы вокруг операторов: `a = b + c`
- Пробелы после запятых: `print(a, b, c)`
- Максимальная длина строки: **79 символов**

**Пример хорошего кода:**
```python
# Плохо
x=5+3
print(x)

# Хорошо
x = 5 + 3
print(x)
```

**Вывод:**
1. `sep` управляет разделителем в `print()`
2. `end` управляет окончанием строки
3. Можно присваивать несколько переменных за раз
4. PEP 8 — стандарт оформления кода

## **Целочисленная арифметика**

---

### **Часть 1: Основы**

**Целые числа:** без кавычек
```python
num = 42        # Целое число
text = "42"     # Строка
```

**Основные операции:**
```python
print(5 + 3)    # 8 (сложение)
print(5 - 3)    # 2 (вычитание)
print(5 * 3)    # 15 (умножение)
print(5 / 3)    # 1.666... (деление - всегда float!)
```

**Порядок операций:**
```python
print(2 + 3 * 4)    # 14 (сначала умножение)
print((2 + 3) * 4)  # 20 (скобки меняют порядок)
```

**Преобразование типов:**
```python
# Строка → число
s = "123"
num = int(s)        # 123

# Число → строка
num = 456
s = str(num)        # "456"

# input() всегда возвращает строку
x = int(input())    # Преобразуем ввод в число
```

### **Часть 2: Дополнительные операции**

**Возведение в степень (`**`):**
```python
print(2 ** 3)       # 8
print(2 ** (-1))    # 0.5
print((-3) ** 2)    # 9
print(2 ** 2 ** 3)  # 256 (справа налево: 2^(2^3))
```

**Целочисленное деление (`//`):**
```python
print(10 // 3)      # 3 (отбрасывает дробную часть)
print(-10 // 3)     # -4 (округляет в меньшую сторону)
print(5 // 9)       # 0
```

**Остаток от деления (`%`):**
```python
print(10 % 3)       # 1
print(10 % 4)       # 2
print(10 % 5)       # 0
print(5 % 9)        # 5 (если делитель больше)
```

**Приоритет операций** (от высшего к низшему):
1. `()` - скобки
2. `**` - степень
3. `*`, `/`, `//`, `%` - умножение и деление
4. `+`, `-` - сложение и вычитание

**Обработка цифр числа:**
```python
num = 123
last_digit = num % 10      # 3 (последняя цифра)
without_last = num // 10   # 12 (число без последней цифры)
```

## **Условный оператор if-else**

**Базовый синтаксис:**
```python
if условие:
    # выполняется если условие True
    команда1
    команда2
else:
    # выполняется если условие False
    команда3
```

**Пример:**
```python
answer = input("Язык? ")
if answer == "Python":
    print("Верно!")
else:
    print("Неверно!")
```

## **Операторы сравнения**

| Оператор | Значение       | Пример       |
|----------|----------------|--------------|
| `==`     | равно          | `x == 5`     |
| `!=`     | не равно       | `x != 5`     |
| `>`      | больше         | `x > 5`      |
| `<`      | меньше         | `x < 5`      |
| `>=`     | больше или равно | `x >= 5`   |
| `<=`     | меньше или равно | `x <= 5`   |

**Примеры:**
```python
x = 10
if x > 0:
    print("Положительное")
if x == 10:
    print("Равно 10")
if x != 5:
    print("Не равно 5")
```

---

## **Цепочки сравнений**

Можно писать условия в одну строку:
```python
x = 5
if 1 <= x <= 10:        # x от 1 до 10 включительно
    print("В диапазоне")

# Работает только с ==, >, <, >=, <=
if a == b == c:         # все три равны
    print("Равны")
```

**Внимание:** `!=` не транзитивен:
```python
# Не проверяет, что все три разные!
if a != b != c:         # НЕ РАБОТАЕТ как ожидается
    ...
```

---

## **Важные моменты**

1. **Отступы:** 4 пробела (блок определяется отступами)
2. **`:`** — обязательно после `if` и `else`
3. **`==`** — сравнение, **`=`** — присваивание
4. `else` — не обязателен

**Правильно:**
```python
if x > 0:
    print(">0")
    print("Позитив")
else:
    print("<=0")
```

**Неправильно:**
```python
if x > 0
    print(">0")     # нет двоеточия
 print("что-то")    # неправильный отступ
```

**Вывод:** `if-else` позволяет программе принимать решения на основе условий.

**Таблица истинности:**
```

True or False = True
False or True = True
False or False = False
```

### **3. not (логическое НЕ)**
```python
# Инвертирует значение
if not (age < 12):      # то же, что age >= 12
    print("Доступ разрешен")
```

**Таблица истинности:**
```
not True = False
not False = True
```

---

### **4. Приоритет операций**
1. `()` - скобки
2. `not` - отрицание
3. `and` - умножение
4. `or` - сложение

**Пример:**
```python
if age >= 12 and grade >= 7 or city == "Москва":
    # Сначала and, потом or

```

### **5. Важные моменты**

**Сокращённое вычисление:**
- `and`: если первое `False`, второе не проверяется
- `or`: если первое `True`, второе не проверяется

**Распространённые ошибки:**

```python
# НЕПРАВИЛЬНО:
```


**Вывод:** Логические операторы позволяют комбинировать условия для сложных проверок.

## **Вложенные и каскадные условия**

---

### **1. Вложенный if (nested)**
```python
if условие1:
    if условие2:            # Внутри первого if
        код1
    else:
        код2
else:
    код3
```

**Пример:**
```python
x = 5
y = 10

if x > 0:
    if y > 0:
        print("1-я четверть")  # x>0 и y>0
    else:
        print("4-я четверть")  # x>0 и y<=0
else:
    if y > 0:
        print("2-я четверть")  # x<=0 и y>0
    else:
        print("3-я четверть")  # x<=0 и y<=0
```

---

### **2. Каскадный if-elif-else**
```python
if условие1:
    код1
elif условие2:      # Проверяется, если условие1=False
    код2
elif условие3:      # Проверяется, если условие2=False
    код3
else:               # Если все условия=False
    код4
```

**Пример (перевод оценки):**
```python
grade = int(input("Оценка (0-100): "))

if grade >= 90:
    print("5")
elif grade >= 80:   # сюда попадаем только если grade < 90
    print("4")
elif grade >= 70:   # сюда только если grade < 80
    print("3")
elif grade >= 60:   # сюда только если grade < 70
    print("2")
else:               # все остальные случаи (grade < 60)
    print("1")
```

---

### **3. Важные отличия**

**Вложенный:**
```python
# Все условия проверяются всегда
if x > 0:
    if y > 0:
        print("1")
    else:
        print("4")
if x <= 0:          # Проверится даже если x>0 было True
    if y > 0:
        print("2")
    else:
        print("3")
```

**Каскадный:**
```python
# Проверка останавливается на первом True
if x > 0 and y > 0:
    print("1")
elif x > 0 and y <= 0:  # Проверится только если первое False
    print("4")
elif x <= 0 and y > 0:  # Проверится только если первые два False
    print("2")
else:
    print("3")          # Все остальные случаи
```

---

### **4. Особенности**

1. **`elif`** = `else if` (иначе если)
2. **`else`** в конце не обязателен
3. Можно использовать **без `else`**:
```python
light = input("Цвет светофора: ")
if light == "красный":
    print("Стой")
elif light == "желтый":
    print("Жди")
elif light == "зеленый":
    print("Иди")
# Если ввели что-то другое - ничего не произойдет
```

4. **Порядок важен** в каскадном:
```python
# НЕПРАВИЛЬНО:
if grade >= 60:
    print("2")
elif grade >= 70:  # Эта строка никогда не выполнится!
    print("3")

# ПРАВИЛЬНО:
if grade >= 70:
    print("3")
elif grade >= 60:  # Теперь работает
    print("2")
```

---

### **5. Когда что использовать**

**Вложенный if:** когда условия **зависят друг от друга**
```python
if user_logged_in:
    if has_permission:
        print("Доступ разрешен")
```

**Каскадный if-elif:** когда есть **несколько взаимоисключающих вариантов**
```python
# Оценка, день недели, меню выбора
if choice == "1":
    print("Опция 1")
elif choice == "2":
    print("Опция 2")
elif choice == "3":
    print("Опция 3")
```

**Вывод:** `elif` делает код чище, когда нужно проверить много взаимоисключающих условий.


**Важно:** `/` всегда возвращает float, даже при делении нацело: `4 / 2` → `2.0`

```python
    print("4")
elif x <= 0 and y > 0:  # Проверится только если первые два False
    print("2")
else:
    print("3")          # Все остальные случаи
```

---

### **4. Особенности**

1. **`elif`** = `else if` (иначе если)
2. **`else`** в конце не обязателен
3. Можно использовать **без `else`**:
```python
light = input("Цвет светофора: ")
if light == "красный":
    print("Стой")
elif light == "желтый":
    print("Жди")
elif light == "зеленый":
    print("Иди")
# Если ввели что-то другое - ничего не произойдет
```

4. **Порядок важен** в каскадном:
```python
# НЕПРАВИЛЬНО:
if grade >= 60:
    print("2")
elif grade >= 70:  # Эта строка никогда не выполнится!
    print("3")

# ПРАВИЛЬНО:
if grade >= 70:
    print("3")
elif grade >= 60:  # Теперь работает
    print("2")
```

---

### **5. Когда что использовать**

**Вложенный if:** когда условия **зависят друг от друга**
```python
if user_logged_in:
    if has_permission:
        print("Доступ разрешен")
```

**Каскадный if-elif:** когда есть **несколько взаимоисключающих вариантов**
```python
# Оценка, день недели, меню выбора
if choice == "1":
    print("Опция 1")
elif choice == "2":
    print("Опция 2")
elif choice == "3":
    print("Опция 3")
```

**Вывод:** `elif` делает код чище, когда нужно проверить много взаимоисключающих условий.

## **Числовые типы данных: int и float**

---

### **1. int (целые числа)**
```python
a = 42             # целое число
b = -17            # отрицательное
c = 1_000_000      # для удобства чтения (выводится как 1000000)
```

**Операции:**
```python
print(5 + 3)    # 8
print(5 - 3)    # 2
print(5 * 3)    # 15
print(5 / 3)    # 1.666... (float!)
print(5 // 3)   # 1 (целочисленное деление)
print(5 % 3)    # 2 (остаток)
print(5 ** 3)   # 125 (степень)
```

**Преобразование:**
```python
s = "123"
n = int(s)           # строка → число: 123
num = int(input())   # ввод → число
```

**Особенность:** неограниченный размер (длинная арифметика)
```python
big = 10**1000       # Работает!
```

---

### **2. float (числа с плавающей точкой)**
```python
pi = 3.14159
e = 2.71828
num = 4.0
```

**Преобразование:**
```python
s = "3.14"
f = float(s)            # строка → float
num = float(input())    # ввод → float
```

**Операции:** те же, что для int
```python
print(4.0 / 2.0)        # 2.0 (всегда float)
print(13.5 // 2.0)      # 6.0
print(13.5 % 2.0)       # 1.5
```

**Важно:** разделитель — точка, не запятая
```python
# Правильно:
x = 3.14

# Неправильно:
x = 3,14    # Это кортеж!
```

---

### **3. Преобразование между типами**

**int → float (автоматически):**
```python
x = 5
y = float(x)    # 5.0
z = x / 2       # 2.5 (автоматически float)
```

**float → int (с отсечением дробной части):**
```python
a = int(3.7)    # 3 (не округление!)
b = int(-3.7)   # -3
c = int(3.0)    # 3
```

**Ошибки преобразования:**
```python
# int('3.14')     # ОШИБКА! Точка в строке
# int('123a')     # ОШИБКА! Не число
# float('abc')    # ОШИБКА!
```

---

### **4. Полезные функции**

```python
# Максимум и минимум
print(max(3, 7, 2))     # 7
print(min(3, 7, 2))     # 2

# Модуль (абсолютное значение)
print(abs(-10))         # 10
print(abs(3.14))        # 3.14
print(abs(-3.14))       # 3.14

# Работают с любыми числами:
print(max(3.5, 2, 4.1)) # 4.1
print(min(-2, -5, 0))   # -5
```

---

### **5. Ключевые различия**

| Свойство | int | float |
|----------|-----|-------|
| **Пример** | `42`, `-7`, `0` | `3.14`, `-2.5`, `0.0` |
| **Деление** | `5/2` → `2.5` (float) | Всегда float |
| **Размер** | Неограничен | Ограничен точностью |
| **Преобразование** | `int("123")` → `123` | `float("3.14")` → `3.14` |
| **Символ-разделитель** | `1_000_000` | `1_000_000.0` |

**Пример программы:**
```python
# Считываем два числа (могут быть float)
a = float(input("Первое: "))
b = float(input("Второе: "))

print("Сумма:", a + b)
print("Максимум:", max(a, b))
print("Модуль разности:", abs(a - b))
```

**Вывод:** `int` для целых чисел, `float` для дробных. Деление всегда возвращает `float`.

## **Модуль math**

---

### **1. Подключение модуля**
```python
import math                    # Полное подключение
print(math.sqrt(25))          # 5.0

from math import sqrt, pi      # Частичное подключение
print(sqrt(25))                # 5.0 (без префикса math)

from math import *             # Все функции (не рекомендуется)
print(ceil(3.2))               # 4
```

---

### **2. Основные функции**

**Округление:**
```python
import math
print(math.floor(3.7))    # 3 (вниз)
print(math.ceil(3.2))     # 4 (вверх)
```

**Сравнение с другими функциями округления:**
```python
print(int(3.7))           # 3 (отсечение дробной части)
print(round(3.5))         # 4 (банковское округление: 3.5 → 4)
print(round(2.5))         # 2 (банковское округление: 2.5 → 2)
print(round(3.14159, 2))  # 3.14 (до 2 знаков)
```

**Корни и степени:**
```python
print(math.sqrt(16))      # 4.0 (квадратный корень)
print(math.pow(2, 3))     # 8.0 (2 в степени 3)
print(2 ** 3)             # 8 (альтернатива pow)
print(16 ** 0.5)          # 4.0 (альтернатива sqrt)
```

**Логарифмы:**
```python
print(math.log(100))      # 4.605... (натуральный ln)
print(math.log10(100))    # 2.0 (десятичный)
print(math.log(8, 2))     # 3.0 (логарифм по основанию 2)
```

**Факториал:**
```python
print(math.factorial(5))  # 120 (5! = 5*4*3*2*1)
```

---

### **3. Тригонометрия**

**Конвертация углов:**
```python
print(math.degrees(math.pi))   # 180.0 (π радиан = 180°)
print(math.radians(180))       # 3.1415... (180° = π радиан)
```

**Основные функции:**
```python
angle = math.radians(30)       # 30° в радианы
print(math.sin(angle))         # 0.5
print(math.cos(angle))         # 0.866...
print(math.tan(angle))         # 0.577...

# Обратные функции (возвращают радианы!)
print(math.degrees(math.asin(0.5)))  # 30.0
```

---

### **4. Константы**
```python
print(math.pi)     # 3.141592653589793
print(math.e)      # 2.718281828459045
```

**Пример:**
```python

r = 5
length = 2 * math.pi * r
print(length)      # 31.4159...
```


**Округление цен:**

### **6. Важные замечания**

1. **Используйте `import math`** вместо `from math import *` (лучшая читаемость)
2. **Тригонометрические функции работают с радианами!**
3. `round()` отличается от `floor()`/`ceil()` (банковское округление)
4. `pow(x, n)` возвращает `float`, `x ** n` сохраняет тип

**Неправильно:**

## **Цикл for**

---

### **1. Базовый синтаксис**
```python
for переменная in range(повторений):
    # тело цикла
    команда1
    команда2
```

**Пример:**
```python
for i in range(5):
    print("Привет")  # Выведет 5 раз
```

---

### **2. Как работает**
```python
# Этот код:
for i in range(3):
    print("Hello")
    print("World")

print("Конец")

# Выведет:
# Hello
# World
# Hello
# World
# Hello
# World
# Конец
```

---

### **3. Переменная цикла**
```python
# i принимает значения 0,1,2,3,4
for i in range(5):
    print(i, "в квадрате =", i**2)

# Выведет:
# 0 в квадрате = 0
# 1 в квадрате = 1
# 2 в квадрате = 4
# 3 в квадрате = 9
# 4 в квадрате = 16
```

---

### **4. Обработка ввода**
```python
# Считать и обработать 3 числа
for i in range(3):
    num = int(input("Введите число: "))
    print("Квадрат:", num * num)

print("Цикл завершен")
```

---

### **5. Несколько циклов**
```python
print("Начало")

for i in range(2):
    print("A")

for j in range(3):
    print("B")

print("Конец")

# Выведет:
# Начало
# A
# A
# B
# B
# B
# Конец
```

---

### **6. Важные моменты**

1. **Отступы определяют тело цикла**
```python
# Правильно:
for i in range(3):
    print("Hello")
    print("World")

# Неправильно:
for i in range(3):
print("Hello")   # Ошибка! Нет отступа
```

2. **Переменная i создаётся автоматически**
3. **range(5)** означает: 0,1,2,3,4 (5 повторений)

---

### **7. Практические примеры**

**Сумма чисел:**

- Переменная цикла (обычно `i`) доступна внутри цикла
