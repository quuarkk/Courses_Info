## **Суть: print() и input()**

**print()** — вывод на экран
```python
print("Текст")           # Просто текст
print(1, 2, 3)          # Несколько значений (через пробел)
print()                 # Пустая строка
```

**input()** — ввод от пользователя
```python
name = input("Имя: ")   # Сохраняет введённое в переменную
```

**Важно:**
- `input()` всегда возвращает **строку**
- Кавычки: `"текст"` или `'текст'` — одинаково
- Переменные хранят данные

**Пример:**
```python
name = input("Как вас зовут? ")
print("Привет,", name)
```

## **Параметры sep и end**

**sep** — разделитель между аргументами print()
```python
print('a', 'b', 'c')          # a b c
print('a', 'b', 'c', sep='-') # a-b-c
print('a', 'b', 'c', sep='')  # abc
```

**end** — что добавлять в конце вывода (по умолчанию \n — новая строка)
```python
print('Привет', end=' ')      # Не переходит на новую строку
print('мир!')                  # Привет мир!
print('Строка1', end='...')   # Строка1...
print('Строка2')               # Строка1...Строка2
```

**Использование вместе:**
```python
print('1', '2', '3', sep='.', end='!')  # 1.2.3!
```

## **Множественное присваивание**

**Запись в одну строку:**
```python
a, b, c = 1, 2, 3  # a=1, b=2, c=3
x = y = z = 0      # x=0, y=0, z=0
```

**Обмен значений:**
```python
a, b = 1, 2
a, b = b, a  # Теперь a=2, b=1
```

## **PEP 8 и комментарии**

**Комментарии:**
```python
# Однострочный комментарий
print('Hello')  # Комментарий после кода

"""
Многострочный
комментарий
(на самом деле строка)
"""
```

**Основные правила PEP 8:**
- Отступы: **4 пробела** (не табуляция)
- Пробелы вокруг операторов: `a = b + c`
- Пробелы после запятых: `print(a, b, c)`
- Максимальная длина строки: **79 символов**

**Пример хорошего кода:**
```python
# Плохо
x=5+3
print(x)

# Хорошо
x = 5 + 3
print(x)
```

**Вывод:**
1. `sep` управляет разделителем в `print()`
2. `end` управляет окончанием строки
3. Можно присваивать несколько переменных за раз
4. PEP 8 — стандарт оформления кода

## **Целочисленная арифметика**

---

### **Часть 1: Основы**

**Целые числа:** без кавычек
```python
num = 42        # Целое число
text = "42"     # Строка
```

**Основные операции:**
```python
print(5 + 3)    # 8 (сложение)
print(5 - 3)    # 2 (вычитание)
print(5 * 3)    # 15 (умножение)
print(5 / 3)    # 1.666... (деление - всегда float!)
```

**Порядок операций:**
```python
print(2 + 3 * 4)    # 14 (сначала умножение)
print((2 + 3) * 4)  # 20 (скобки меняют порядок)
```

**Преобразование типов:**
```python
# Строка → число
s = "123"
num = int(s)        # 123

# Число → строка
num = 456
s = str(num)        # "456"

# input() всегда возвращает строку
x = int(input())    # Преобразуем ввод в число
```

### **Часть 2: Дополнительные операции**

**Возведение в степень (`**`):**
```python
print(2 ** 3)       # 8
print(2 ** (-1))    # 0.5
print((-3) ** 2)    # 9
print(2 ** 2 ** 3)  # 256 (справа налево: 2^(2^3))
```

**Целочисленное деление (`//`):**
```python
print(10 // 3)      # 3 (отбрасывает дробную часть)
print(-10 // 3)     # -4 (округляет в меньшую сторону)
print(5 // 9)       # 0
```

**Остаток от деления (`%`):**
```python
print(10 % 3)       # 1
print(10 % 4)       # 2
print(10 % 5)       # 0
print(5 % 9)        # 5 (если делитель больше)
```

**Приоритет операций** (от высшего к низшему):
1. `()` - скобки
2. `**` - степень
3. `*`, `/`, `//`, `%` - умножение и деление
4. `+`, `-` - сложение и вычитание

**Обработка цифр числа:**
```python
num = 123
last_digit = num % 10      # 3 (последняя цифра)
without_last = num // 10   # 12 (число без последней цифры)
```

## **Условный оператор if-else**

**Базовый синтаксис:**
```python
if условие:
    # выполняется если условие True
    команда1
    команда2
else:
    # выполняется если условие False
    команда3
```

**Пример:**
```python
answer = input("Язык? ")
if answer == "Python":
    print("Верно!")
else:
    print("Неверно!")
```

## **Операторы сравнения**

| Оператор | Значение       | Пример       |
|----------|----------------|--------------|
| `==`     | равно          | `x == 5`     |
| `!=`     | не равно       | `x != 5`     |
| `>`      | больше         | `x > 5`      |
| `<`      | меньше         | `x < 5`      |
| `>=`     | больше или равно | `x >= 5`   |
| `<=`     | меньше или равно | `x <= 5`   |

**Примеры:**
```python
x = 10
if x > 0:
    print("Положительное")
if x == 10:
    print("Равно 10")
if x != 5:
    print("Не равно 5")
```

---

## **Цепочки сравнений**

Можно писать условия в одну строку:
```python
x = 5
if 1 <= x <= 10:        # x от 1 до 10 включительно
    print("В диапазоне")

# Работает только с ==, >, <, >=, <=
if a == b == c:         # все три равны
    print("Равны")
```

**Внимание:** `!=` не транзитивен:
```python
# Не проверяет, что все три разные!
if a != b != c:         # НЕ РАБОТАЕТ как ожидается
    ...
```

---

## **Важные моменты**

1. **Отступы:** 4 пробела (блок определяется отступами)
2. **`:`** — обязательно после `if` и `else`
3. **`==`** — сравнение, **`=`** — присваивание
4. `else` — не обязателен

**Правильно:**
```python
if x > 0:
    print(">0")
    print("Позитив")
else:
    print("<=0")
```

**Неправильно:**
```python
if x > 0
    print(">0")     # нет двоеточия
 print("что-то")    # неправильный отступ
```

**Вывод:** `if-else` позволяет программе принимать решения на основе условий.

**Таблица истинности:**
```

True or False = True
False or True = True
False or False = False
```

### **3. not (логическое НЕ)**
```python
# Инвертирует значение
if not (age < 12):      # то же, что age >= 12
    print("Доступ разрешен")
```

**Таблица истинности:**
```
not True = False
not False = True
```

---

### **4. Приоритет операций**
1. `()` - скобки
2. `not` - отрицание
3. `and` - умножение
4. `or` - сложение

**Пример:**
```python
if age >= 12 and grade >= 7 or city == "Москва":
    # Сначала and, потом or

```

### **5. Важные моменты**

**Сокращённое вычисление:**
- `and`: если первое `False`, второе не проверяется
- `or`: если первое `True`, второе не проверяется

**Распространённые ошибки:**

```python
# НЕПРАВИЛЬНО:
```


**Вывод:** Логические операторы позволяют комбинировать условия для сложных проверок.

## **Вложенные и каскадные условия**

---

### **1. Вложенный if (nested)**
```python
if условие1:
    if условие2:            # Внутри первого if
        код1
    else:
        код2
else:
    код3
```

**Пример:**
```python
x = 5
y = 10

if x > 0:
    if y > 0:
        print("1-я четверть")  # x>0 и y>0
    else:
        print("4-я четверть")  # x>0 и y<=0
else:
    if y > 0:
        print("2-я четверть")  # x<=0 и y>0
    else:
        print("3-я четверть")  # x<=0 и y<=0
```

---

### **2. Каскадный if-elif-else**
```python
if условие1:
    код1
elif условие2:      # Проверяется, если условие1=False
    код2
elif условие3:      # Проверяется, если условие2=False
    код3
else:               # Если все условия=False
    код4
```

**Пример (перевод оценки):**
```python
grade = int(input("Оценка (0-100): "))

if grade >= 90:
    print("5")
elif grade >= 80:   # сюда попадаем только если grade < 90
    print("4")
elif grade >= 70:   # сюда только если grade < 80
    print("3")
elif grade >= 60:   # сюда только если grade < 70
    print("2")
else:               # все остальные случаи (grade < 60)
    print("1")
```

---

### **3. Важные отличия**

**Вложенный:**
```python
# Все условия проверяются всегда
if x > 0:
    if y > 0:
        print("1")
    else:
        print("4")
if x <= 0:          # Проверится даже если x>0 было True
    if y > 0:
        print("2")
    else:
        print("3")
```

**Каскадный:**
```python
# Проверка останавливается на первом True
if x > 0 and y > 0:
    print("1")
elif x > 0 and y <= 0:  # Проверится только если первое False
    print("4")
elif x <= 0 and y > 0:  # Проверится только если первые два False
    print("2")
else:
    print("3")          # Все остальные случаи
```

---

### **4. Особенности**

1. **`elif`** = `else if` (иначе если)
2. **`else`** в конце не обязателен
3. Можно использовать **без `else`**:
```python
light = input("Цвет светофора: ")
if light == "красный":
    print("Стой")
elif light == "желтый":
    print("Жди")
elif light == "зеленый":
    print("Иди")
# Если ввели что-то другое - ничего не произойдет
```

4. **Порядок важен** в каскадном:
```python
# НЕПРАВИЛЬНО:
if grade >= 60:
    print("2")
elif grade >= 70:  # Эта строка никогда не выполнится!
    print("3")

# ПРАВИЛЬНО:
if grade >= 70:
    print("3")
elif grade >= 60:  # Теперь работает
    print("2")
```

---

### **5. Когда что использовать**

**Вложенный if:** когда условия **зависят друг от друга**
```python
if user_logged_in:
    if has_permission:
        print("Доступ разрешен")
```

**Каскадный if-elif:** когда есть **несколько взаимоисключающих вариантов**
```python
# Оценка, день недели, меню выбора
if choice == "1":
    print("Опция 1")
elif choice == "2":
    print("Опция 2")
elif choice == "3":
    print("Опция 3")
```

**Вывод:** `elif` делает код чище, когда нужно проверить много взаимоисключающих условий.


**Важно:** `/` всегда возвращает float, даже при делении нацело: `4 / 2` → `2.0`

```python
    print("4")
elif x <= 0 and y > 0:  # Проверится только если первые два False
    print("2")
else:
    print("3")          # Все остальные случаи
```

---

### **4. Особенности**

1. **`elif`** = `else if` (иначе если)
2. **`else`** в конце не обязателен
3. Можно использовать **без `else`**:
```python
light = input("Цвет светофора: ")
if light == "красный":
    print("Стой")
elif light == "желтый":
    print("Жди")
elif light == "зеленый":
    print("Иди")
# Если ввели что-то другое - ничего не произойдет
```

4. **Порядок важен** в каскадном:
```python
# НЕПРАВИЛЬНО:
if grade >= 60:
    print("2")
elif grade >= 70:  # Эта строка никогда не выполнится!
    print("3")

# ПРАВИЛЬНО:
if grade >= 70:
    print("3")
elif grade >= 60:  # Теперь работает
    print("2")
```

---

### **5. Когда что использовать**

**Вложенный if:** когда условия **зависят друг от друга**
```python
if user_logged_in:
    if has_permission:
        print("Доступ разрешен")
```

**Каскадный if-elif:** когда есть **несколько взаимоисключающих вариантов**
```python
# Оценка, день недели, меню выбора
if choice == "1":
    print("Опция 1")
elif choice == "2":
    print("Опция 2")
elif choice == "3":
    print("Опция 3")
```

**Вывод:** `elif` делает код чище, когда нужно проверить много взаимоисключающих условий.

| **Размер** | Неограничен | Ограничен точностью |
| **Преобразование** | `int("123")` → `123` | `float("3.14")` → `3.14` |

### **6. Важные отличия от for**

| Особенность | for | while |
|-------------|-----|-------|

## **Обработка цифр числа**

---

### **1. Метод с while (основной)**

**Как получить цифры справа налево:**
```python
num = int(input())
while num > 0:
    digit = num % 10      # последняя цифра
    print(digit)          # обрабатываем
    num = num // 10       # убираем последнюю цифру
```

**Пример: число 123 → вывод: 3 2 1**

---

### **2. Практические задачи с while**

**Сумма цифр:**
```python

    num //= 10

```

**Количество цифр:**
```python
num = int(input())
count = 0
while num > 0:
    count += 1
    num //= 10

```

**Проверка на наличие цифры 7:**
```python

    if num % 10 == 7:
        has_seven = True

print("YES" if has_seven else "NO")
```

**Наибольшая цифра:**
```python
num = int(input())
max_digit = 0
while num > 0:
    digit = num % 10
    if digit > max_digit:
        max_digit = digit
    num //= 10
print("Наибольшая цифра:", max_digit)
```

### **3. Метод с for (через строку)**

### **4. Метод с for (математический)**

**Слева направо:**
```python
num = 8619

for i in range(1, n + 1):
    # Формула: (num // 10**(n-i)) % 10

    print(f"{i}-я цифра: {digit}")
```

**Вывод:**

### **5. Частые задачи**

**Произведение цифр:**

**Проверка на чётность цифр:**

**Число в обратном порядке:**

### **6. Когда какой метод использовать**

**while (цикл):**
- Когда нужно обработать все цифры
- Когда не важен порядок (или нужен справа налево)
- Когда число может быть 0 (проверяем `num > 0`)

**for через строку:**
- Когда важен порядок слева направо
- Когда нужен простой код
- Когда нужно считать конкретные цифры

**Пример: подсчёт нулей в числе**
```python
# Способ 1: через while
count = 0
n = int(input())
while n > 0:
    if n % 10 == 0:
        count += 1
    n //= 10
print("Нулей:", count)

# Способ 2: через строку
n = input()  # уже строка!
count = n.count('0')
print("Нулей:", count)
```

## **Вложенные циклы**

---

### **1. Базовый пример**
```python
# Внешний цикл
for i in range(3):
    # Внутренний цикл
    for j in range(2):

```
**Вывод:**
```

i=0, j=1
i=1, j=0
i=1, j=1
i=2, j=0
i=2, j=1
```

### **2. Электронные часы**
```python
for hours in range(24):
    for minutes in range(60):
        for seconds in range(60):
            print(f"{hours:02}:{minutes:02}:{seconds:02}")
```

**Количество итераций:** 24 × 60 × 60 = 86 400

### **3. Таблица умножения**

### **5. break и continue во вложенных циклах**

**break прерывает только внутренний цикл:**
```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break  # выходит только из цикла по j
        print(i, j)
```
**Вывод:** (j никогда не будет 1)
```
0 0
1 0
2 0
```

**continue во внутреннем цикле:**
```python
for i in range(3):
    for j in range(3):
        if j == 1:
            continue  # пропускает j=1
        print(i, j)
```
**Вывод:**
```
0 0
0 2
1 0
1 2
2 0
2 2
```
